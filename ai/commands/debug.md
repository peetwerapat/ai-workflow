# /debug — Investigate a Failure

Respond in Thai. Input: **$ARGUMENTS**. Follow `~/.ai/workflows/implementation.md` › Select assistance.

Use debugger with expected/actual behavior, safe log excerpts, relevant paths, environment, and attempts already made. Gather available evidence first; ask only for reproduction details that cannot be inferred and are needed to distinguish causes.

This command authorizes read-only investigation. Report whether the cause was reproduced, confirmed from code/evidence, or remains a hypothesis. Include the smallest correction and practical verification steps. If the developer also explicitly asks to fix it, the main assistant may implement within that authorization and follow the shared validation/completeness protocol. The helper remains read-only.
